# 帝国亲子沙盒 · 统帅试炼

亲子向古代战争沙盒：配兵布阵、自动会战、读战报复盘。Phaser 3 等距渲染 + Node 原生测试，
纯前端单机 + 局域网双人对战，无后端依赖（对战服务器仅为消息中继，不做游戏逻辑）。
当前优化与验收以桌面浏览器和键鼠操作为准。

## 快速开始

```bash
npm install
npm run dev        # 本地开发/试玩 → http://localhost:5301（vite.config.js 固定端口；arena 对战服为 5300）
```

## 常用命令

| 命令 | 说明 |
|---|---|
| `npm run dev` | Vite 开发服务器（试玩入口） |
| `npm test` | 全量测试（node --test，纯模拟层，无需浏览器） |
| `npm run build` | 构建产物到 `dist/` |
| `npm run arena` | 启动局域网对战服务器（托管 `dist/` + WebSocket 房间） |
| `node tools/perf-benchmark.mjs` | 运行新旧索敌对照基准，输出耗时与状态哈希 |

## 🌐 局域网对战（两台电脑，同一 WiFi）

**房主（红方）**：

```bash
npm run build && npm run arena
```

启动后会打印本机局域网地址，例如 `http://192.168.x.x:5300`。房主浏览器打开该地址，
点「🏰 创建房间」得到 4 位房间码。

**另一位玩家（蓝方）**：同一局域网的浏览器打开上面的地址 → 「🔵 加入房间」→ 输入房间码。

双方点「✅ 就绪」自动开战：260×180 山河大图、十一据点、军费征兵、民夫建寨、弓手驻塔与医师医帐。
两台电脑请使用同款浏览器（都是 Chrome），且**两边都是最新页面**——服务器开局前会校验两端
游戏版本，一边是旧标签页时会提示双方刷新（混版本联机同一命令会打出不同结果，必须拦下）。
命令行窗口保持开着（关掉即房间解散）。

> 技术说明：联机为锁步同步——两端各自运行完全相同的确定性模拟，网络只传
> 玩家命令（买兵/营令/施工/驻塔/攻寨），每 2 秒交换状态哈希校验一致性。详见 `docs/DETERMINISM.md`。

## 玩法模式

- **🚩 领土征服**：十一据点产军费、老家征兵、点营下令；占多数旗抽干敌方票数，或摧毁敌方大本营获胜（支持 AI 对手或局域网真人）
- **⚑ 占点三旗 / 🛒 辎重护送 / ⚔️ 战阵演练**：3~5 分钟快速一局
- **🎖 挑战战役**（5 关）/ **⛰ 地形演练**（坡地/树林/河桥）/ **⚔️ 自由对战**（4000 金币配兵千人沙盒）

领土模式开局各有两名民夫、一座主寨和一座空箭塔，**三队骑兵**（占马场前就用这些）。
**骑兵需要马场**：地图北上翼有两座中立马场（西马场/东马场，金圈标记），
占领任意一座才能征骑兵；丢光马场只是断补充，已在场的骑兵照打——夺回马场即可重启骑兵线。
开战后在「前线建设」选民夫，
点「筑/续营寨」再点己方据点，花 160 军费，到场施工 18 秒；营寨完工后可花 120 军费建塔，施工 14 秒；
也可花 140 军费建**医帐**（施工 15 秒），该据点疗伤容量 8→16、疗伤速度 2.2 倍。
民夫有**有限自卫**（攻击 12 / 间隔 1.4 秒 / 近战 0.9 格）：只还手贴到身边的敌人，不追击、不占旗；
近身交战期间施工进度冻结，脱离交战后继续原任务，进度不重置——所以民夫替代不了同规模剑士。
选弓兵所在营或单个弓手，点「建筑行动 → 驻入箭塔」再点己方完工塔：最多四人，需步行到塔旁才登塔；
指令下达后单位信息显示「正在前往箭塔」、入塔后显示「驻塔中」，塔下常显「弓手 N/4（+M 前往中）」，
选中含弓手的部队时，可入驻的己方完工塔会高亮。塔内弓手按自己的攻击冷却射箭。
选塔可让弓手出塔，毁塔也会释放存活驻军。
塔满 / 未完工 / 敌方 / 没选弓手等情况会直接说明原因；容量把"正在前往"的弓手一并算入，不会超额预订。
选营点「攻击建筑」再点敌方塔或营寨可攻城；普通营令可中断前往入塔或攻寨。
据点易主不会把尚存的敌方建筑转给己方，需先摧毁再建设。

**六类据点特色**（地图标签写明「地形」与「占领奖励」，占领/失去即时提示）：

| 据点 | 地形原有 | 占领后奖励（按当前归属生效） |
|---|---|---|
| 马场 | 北岭缓坡草场 | 骑兵征募权（拥有任一即可，两座不叠加） |
| 林口 | 林内移速：骑兵 55% / 其他 85% | 本点施工时间 −20%（施工速度 ×1.25，不降费用） |
| 桥头 | 跨河通道与桥面 | 工事：本点建筑受到伤害 −10%（只护本点，不给全军加防） |
| 中央高地 | 居高射程 + 俯攻加成（对双方生效） | 稳固军心：驻守营队在旗点 8 格内士气损失 −10% |
| 渡口 | 中央浅滩可通行、蹚水 70% | 通行：浅滩移速 70% → 85%（拥有任一即可，不叠加） |
| 路口 | 下翼迂回岔路 | 补给：本点伤兵收容 +4（8→12，医帐 16→20） |

大本营没有旗位，不套用任何旗点奖励；局部奖励只作用于该据点，易主立即失效。

**伤兵收容与医疗**：崩溃的士兵不再只靠接应重整——他们会自动撤往最近的己方据点
（含大本营）疗伤：进点站定，按损血比例回满 HP 与士气（满损约 20 秒），痊愈后自动归队再战。
每据点同时疗伤 8 人（满员自动改投次近据点）；据点失守则疗伤中断、再次溃逃。
疗伤中的士兵不战斗、不占旗、可被攻击——围点断疗或用己方箭塔掩护疗伤点都是有效战术。
军费还可征**医师**（48 军费）：无攻击，随营行军并缓慢急救身边两名最重伤员；
选医师点「驻入医帐」可让该据点疗伤再提速（每名驻帐医师 +0.8 倍，最多两名）。

### 操作提示

领土战斗右下角常驻营队选择。点击营号或按数字键 `1–9` 选营，`Tab` 切到下一营，
`F` 定位所选营；点击「移动并驻守」后再点地图下令，`Esc` 取消选点。
「选择据点夺旗」可展开全部据点；夺下目标后该营恢复自主作战，需要守住位置时请另下驻守令。
驻守、集结和建设的选点模式互斥，页面持续显示当前操作提示。单机可用空格暂停或继续，
按钮获得焦点时空格仍用于激活按钮；联机不允许单方暂停。

左下角征兵条显示兵种、费用、禁用原因和训练队列，支持长按连续征兵。建设面板可主动关闭。
单兵信息优先显示当前任务、伤势和士气，展开详情再查看地形与战斗参数。
地图准备期间显示加载进度，完成后才能开战。性能读数的悬浮提示包含真实帧间隔与模拟耗时；
联机停等会显示「同步等待」。测量方法与限制见 [性能记录](docs/PERFORMANCE.md)。

## 代码结构

```
js/game.js            战斗场景编排壳（模式编排 + sim→render 单行委托，渲染实现一律进 js/render/）
js/battle/            纯模拟层：core 战斗核 / economy 领土经济 / battalion 营队 /
                      recruit 征兵 / morale-bridge 士气桥 / territory-bridge 领土节拍 /
                      camps 建造/驻塔/攻寨 / worker 民夫自卫 / site-traits 据点特色参数与派生状态 /
                      healing 溃兵收容与医师医帐 / spatial 空间哈希 /
                      report 战报 / determinism 确定性约定
js/render/            渲染层（BattleRenderer 门面）：world 地貌海面装饰烘焙 / units 单位同步 /
                      fx 特效 / overlay 覆盖层 / camera 相机装配 / metrics 世界度量 / sprites 精灵轮廓
js/snd.js             WebAudio 合成音效（无外部文件）
js/lobby.js           局域网房间流程（lobbyMethods 并入 UI）
js/tactics/           战术四组：deploy 布阵 / guards 守备纪律 / rally 集结波次 / steps 逐帧编排（原型混入 TacticsSystem）
js/net/               锁步联机：lockstep 调度与哈希 / arena-client 房间客户端
js/terrain|navigation 地形高度场与寻路（棋盘尺寸参数化，默认 70×70，领土图 260×180）
server/arena.mjs      局域网对战服务器（静态托管 + WebSocket 房间中继）
tests/                战斗规则/模式/营队/营寨/锁步一致性/服务器协议/连续河岸回归
```

铁律：`js/battle/` 与 `js/net/` 不碰 Phaser、不碰 DOM；渲染实现只进 `js/render/`，场景上仅留单行委托——新功能禁止把渲染/模拟实现堆回 game.js。
地图尺寸经 `js/board.js` 读取，禁止缓存旧尺寸。

领土山河图使用 `js/render/terrain-materials.js` 烘焙连续材质与真实高度坡面，地面以
512px 分块纹理和独立 Image 绘制，分帧生成并优先处理镜头附近，支持视口剔除；切换地图会取消旧任务并释放纹理。
`terrain-boundaries.js` 对水面、桥下水域和浅滩合并计算外岸距离，避免河段内部出现假岸线。
树木与单位共用脚底深度排序，阴影烘焙进地面，小地图保持屏幕大小并支持点击定位。
材质与透明装饰图集位于 `public/assets/terrain/`，本次由 ImageGen 原创生成；装饰图集
前三棵树占上方 620px，后三种装饰占下方 404px，运行时裁取，完整保留树根。
以上均为渲染实现，地形高度、碰撞、坡速、旗点与锁步模拟仍读取原有 `Terrain` 数据。
