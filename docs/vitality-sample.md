## 本次改变

- 每队 6 名剑盾 + 2 名骑兵，使用真实 `stepSkirmish`，可以自由布阵、交战、暂停、重置，显式近看 / 全景。
- 独立 `public/assets/3d-sample/vitality/` 模型：剑盾收束胸腰体块、贴体肩袖、叠片腰甲和浅膝甲；骑兵延续同套人体，马腹/肩部体块、沿马背垂落鞍毯、鞍桥、脚蹬、缰具细节。依然是简洁成人低多边形风格，属于有限改善。
- 新动作在独立 Blender 源中烘焙：剑盾行走肩胯反旋、头部稳定、攻击蓄力 / 前送 / 回收；骑兵支撑蹄与抬蹄回收轨迹、髋胸头吸收马背运动。攻击命中仍为 11/24 秒；Hit / Death 优先级及终态保留。步频只按实际位移匹配新步幅，不加速攻击或总时钟。
- 30% 缩放施加于克隆模型实例，先于接地注册。碰撞 / 接敌距离 / 线速度 / 冲锋距离及推开距离 / 阵列间距同时按 0.3 适配，角色环、尘土和命中反馈也随尺寸适配。两档初始阵列接敌约数秒，不必等远程行军。
- 世界、相机、塔和地形不缩放；「近看交战」由用户显式选择，两档均 18m（全景均 44m）。30% 在全景明显很小是本次明确对照要求。

## 可比边界

尺度 adapter 仅转换长度 / 线速度后调用原模拟，HP、伤害、冷却、真实事件与秒保持。纯规则测试在同一 dt 下两档 2400 帧归一化状态和事件相同；这**不代表浏览器实战同战果**：真实 dt 不同，阵列缩放后落在不同地形位置，姿态与反馈会不同。场景边界保持原 ±17 / ±13，30% 仍可在全场下令移动。

新样板沿用核心绕肩避让，未叠加原混合主场的 W1 / W2 战线规划。原混合 32 人的候选逻辑不受影响。骑兵整马侧倒、部分机械姿态、肩膝简化、主镜下微小动作难辨仍存在；不能把本次样板称为全面模型升级或容量优化。
