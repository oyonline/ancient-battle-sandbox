## 五项实际差异
- **时钟**：2D `js/battle/core.js:14,59-66` 累积毫秒、固定1/60秒步、倍率通过步数实现；网络 `js/game.js:724-747` 等双方回合包，再增固定时钟。3D `js/three-demo/main.js:220` 每显示帧截断dt到0.05秒，`combat-model.js:37-38` 再截断并直接推进，无累积补步。掉帧改变离散采样，不能直接继承2D确定性保证。
- **命令**：2D `js/net/lockstep.js:102-108` 固定红包在前、蓝包在后，`js/game.js:754-790` 校验阵营/营令并调度；3D `main.js:163-165` 鼠标事件立即改target、取消准备出手和冲锋，直接带动画操作，无回合命令队列。3D只有两队个体移动和开战开关，并无营、驻守、撤退、补给等2D语义。
- **随机/阈值**：2D `js/units.js:773-788` 按镜像坐标与兵种播种LCG，`js/battle/determinism.js:8-39` 量化离散决策。3D combat模型无Math.random；重叠方向来自id公式 (`combat-model.js:12`)，冷却错开id%5 (`:7`)，不等于2D种子/换座规则。2D视觉随机存在于 `game.js:558,574` / `render/fx.js:202+`，不是因此要全局替换随机。
- **顺序**：2D `battle/core.js:80-108,139-153` 帧首快照→规划/延迟动作→统一位移/分离→箭→迎击→批量伤害→士气。3D `combat-model.js:38,80-98` 箭先直接扣血→规划/位移→冲锋直接扣血→逐单位待定近战扣血→分离/死亡事件，数组先后可取消后手pendingStrike。不能把两套事件顺序合并而保持既有基准。
- **伤害/箭语义**：2D `units.js:870-917` 原攻击、反骑/地形/阵形/建筑倍率、护甲、最少1伤害、批量队列与有效伤害报告；3D `combat-model.js:3-4,85,90` 固定36/14/16/12等直接减hp。2D箭 `render/fx.js:24-79` 预测固定落点、到期查附近最近敌人（平局id）、建筑单独目标；3D `combat-model.js:24-34` 每步扫掠圆碰撞沿途首命中。这是规则差异，不是视觉差异。
