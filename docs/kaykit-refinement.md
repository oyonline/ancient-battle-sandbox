# KayKit 剑盾动作优化（2026-10-14）

用户明确选择 KayKit 风格，并授权改善关节、格挡和倒地；这项选择不等于已认可本轮新动作。`model-duel.html` 默认两名 KayKit，`?kay=previous` 为同款上一版动作；“对照改进前 / 看优化后”切换并以相同 seed 重开。Q、混合、原模型和骑兵入口保留。

实际参考身高仍为 0.783689m（30%）。SwordDuel、HP140、seed728、三招伤害/时序与格挡概率均未改。原 KayKit GLB/JSON 和原 LibraryAnimation 保留；新资产 kaykit-refined 使用同作者同源网格、权重、持握槽和 Death_B，未改蒙皮权重。

独立 KayRefinement 层把接触权重改为零斜率入出，并用85ms有界过渡减轻换姿跳变。正面守势按可见来袭抬盾准备，完全不读取未来格挡随机结果；真实 block 才产生髋胸承力、脚锚保持和攻击者短回弹。接触目标随迎盾权重连续变化，实际 block 后35ms补足，不瞬间切胸到盾。

死亡用作者原生 Death_B 的屈膝前伏与末态松弛。原前伏会把头盔放进胜者腿间，已在死亡开始依据相对位置选侧向空地，0.08–0.93秒渐进转向67.6度后固定；只修改呈现朝向，模拟位置、事件和伤害不变。不是布娃娃或完整逐脚物理。

验证：20/20受影响测试，build退出0并输出model-duel.html；正常真实局errors=[]，16hit/2block/1death，最终显示0/2HP，80次抽样。暂停冻结，重开恢复。真实block前后60Hz剑尖位移2.11/2.66cm，无胸盾目标突跳。实际渲染顶点：死亡核心支撑最低约0，末脚局部−6.26mm；交战非walk足底最低新−6.35mm/旧−5.89mm。开场原生Walking_A最低−16.49mm在新旧完全相同，是保留的源动作基线，不能伪称本轮全时段零穿地。

主证据见 `visual-iteration/kaykit/summary.json` 和交战/死亡截图；完整正常速度raw/WebM在本机临时证据目录。保留说明：转身脚步仍近原地转脚，非逐脚求解；格挡和源风格仍需用户亲自评价。无commit/push/merge/deploy。
