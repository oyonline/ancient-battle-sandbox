# 死亡动作源素材

四张 PNG 由内置 ImageGen 生成，参考项目已有兵种造型。完整提示词见 `prompts.json`。
每张原图是 3 列 × 2 行的六帧动作：失衡、屈膝、下落、侧倒、接地、静止。
骑兵包含马匹折腿与骑手摔落；没有用旋转站姿或压扁站姿代替动作。

在仓库根目录运行：

```sh
python3 tools/build_death_sprites.py
```

脚本只做透明边缘整理、裁格、统一尺寸、红蓝换色和图集打包。
每套六帧共用一个缩放比例，首帧匹配现有行走图集的可见高度，保留源格内的横向位置。
地面锚点固定在输出格的 `y=178`；`manifest.deaths` 同时记录格宽、格高、锚点和绝对显示比例。
生成结果位于 `assets/units/death/`，清单更新至 `assets/manifest.json` 和 `assets/manifest.js`。

用本地服务打开 `tools/visual-check.html` 可查看四兵种红蓝样板、逐步推进倒地、切换慢放、冲锋小战和千人混战。
最后一帧与接触阴影直接盖印到战场留痕层，运行时不再切换为另一张尸体图。
